# 灰盒瓦片

`tiles.svg` 是本项目直接绘制的 48 × 16 px 占位图集，无第三方素材；`tileset.tres` 是共享 `TileSet`。此图集用于房间结构验收，不代表正式美术。

1 U = 16 px，瓦片格与图集切片均 16 × 16 px；素材源 ID 固定为 0。图集坐标 `(0,0)` 是地板、`(1,0)` 是墙/顶、`(2,0)` 是台阶。三种瓦片均使用以格中心为参考的完整 16 × 16 px 实心碰撞，World 层 1；不会与道具实例身份混用。

替换素材时保留源 ID、切片坐标、尺寸及碰撞，图片可以改变视觉表现。若正式图集改变排列，需要显式迁移已铺格子的引用，不能把图片更换当作自动迁移。房间 `Terrain` 可以直接选择本 `TileSet` 绘制，新增地形类型先明确可通行范围和碰撞行为。

SVG 顶部高亮只是可站表面的视觉提示；真实地板高度由瓦片碰撞决定。对齐参考是16 px网格与 tile origin；角色、门等场景对象另用脚底/门槛作为场景原点，不从图片中心推导碰撞。
