# ENV-0005：GitHub connector 与本机 CLI 的仓库权限不同

- status: resolved
- channel: environment_setup
- category: environment/authorization
- first_seen: 2026-10-01
- code_state: 原首版提交 172c38e，未改游戏代码。

## 原始证据与影响

GitHub connector 返回用户 login=gzaii-promax，但 list_repositories 返回空列表，读取 `repos/gzaii-promax/Codename_Astra` 返回 404 Not Found。仅凭该结果无法区分权限不足与仓库不存在，不应据此创建重复仓库。

本机 gh auth status 最初退出 1，明确表示尚未登录。gh 工具本身已执行 --version 成功，归档 checksum 与官方发布文件一致，故不是缺依赖或引擎问题。

## 处理与验证

用户通过 `gh auth login --hostname github.com --git-protocol https --web` 的官方设备授权页登录。本机 CLI 随后确认账号 gzaii-promax（keyring），指定仓库 private=true、viewerPermission=ADMIN、permissions.push=true、default_branch=main，分支列表为空。git fetch origin 成功。

这证明当前 CLI 可访问指定仓库；不证明 connector 权限也已改变。后续仓库操作使用已核实的 CLI，凭据不写入源码或报告。没有修改游戏逻辑、无需以业务代码修复授权问题。
