# ENV-0001：Xcode 许可阻止系统 Git 和 Python 执行

- status: resolved
- channel: automated_environment_check
- category: environment
- first_seen: 2026-10-01
- affected: `/usr/bin/git`、`/usr/bin/python3`
- original_message: `You have not agreed to the Xcode license agreements.`

## 复现与判断

运行 `git --version` 或 `python3 --version`，工具在进入自身逻辑前被 Xcode 许可状态阻止。这不是游戏代码、仓库权限或缺少 Python/Git 的问题。

## 尝试与处理

1. 沙箱内 `sudo -n -v` 返回 `operation not permitted`。
2. 获准在沙箱外尝试 `sudo -n /usr/bin/xcodebuild -license accept`，返回 `sudo: a password is required`，未完成许可接受。
3. 用户在系统终端阅读并完成许可确认，回复“已完成”。
4. 重新执行系统命令，得到 `git version 2.54.0 (Apple Git-157)`、`Python 3.9.6`，退出码均为 0。

## 复发处理

先运行上述两个版本查询命令确认症状。管理员密码由用户在自己的终端输入，不向 agent 提供。只有版本查询实际成功后，才能将记录关闭。
