# ENV-0002：沙箱网络限制导致官方域名无法解析

- status: resolved
- channel: automated_environment_check
- category: environment
- first_seen: 2026-10-01
- original_message: `curl: (6) Could not resolve host: godotengine.org`

## 复现与判断

沙箱内使用 curl 读取 Godot 官方下载页时失败。不能由此判断网址错误或需要修改游戏代码。

## 尝试与验证

经授权使用沙箱外网络读取同一官方网页成功；随后从官方链接下载 Godot 4.7.2 和维护者链接下载 GUT 9.7.1，curl 均以 0 退出。gdtoolkit 4.5.0 在项目隔离环境中安装成功。

官方来源及下载文件 SHA256 记录在 `tools/toolchain.json`。后续重新下载如果出现同一症状，先确认执行环境的网络权限；不能通过修改项目代码或关闭 TLS 校验来修复。
