# ENV-0003：沙箱内 Godot 签名检查失败

- status: resolved
- channel: automated_environment_check
- category: environment
- first_seen: 2026-10-01
- affected: `.tools/godot-4.7.2/Godot.app`
- original_message: `invalid signature (code or signature have been modified)`

## 判断依据

沙箱内 `codesign -dvvv` 显示 `Authority=(unavailable)`，严格校验返回非零。此时文件签名是否损坏尚不能确定。

## 验证与结果

对同一个未经修改的应用，获准在沙箱外执行 `codesign --verify --deep --strict --verbose=2`，退出码 0，输出 `valid on disk` 和 `satisfies its Designated Requirement`。

证据支持本次失败与执行环境有关。没有重新签名、删除隔离属性或更改应用内容。未来同类报错仍须校验具体文件，不能自动当作沙箱误报忽略。
