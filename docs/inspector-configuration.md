# Inspector 配置与运行状态契约

配置归属约定适用于后续模块开发；设计数值与机制回归见 [design-baselines.md](design-baselines.md)。

## 配置来源

- 脚本声明提供未保存覆盖值时的默认值；场景、资源、继承场景与实例保存的属性覆盖是该实例的配置来源。初始化、`_ready()` 和重置读取配置，不得无条件重注入默认值。
- 合法的 `0`、`false` 和空值按属性契约解释，不能用真假判断当作“未配置”。非法值遵循模块校验，不增加未记录的默认回退来掩盖错误。
- 配置、派生值与运行状态分别保存。例如保护时长是配置，剩余保护时间是运行状态；起跳速度由配置计算。初始化可以建立派生缓存，重置可以清除状态，二者不能改写源配置。
- 技能等级解析先创建独立运行副本，再应用等级覆盖，不修改基础 `.tres`。运行中修改配置、升级或显式角色映射须由对应 API 和模块契约规定，不能偷偷恢复默认值。
- 保存配置生效指重新加载并启动实例后的行为。运行中是否热更新、缓存何时重新绑定，由所属模块说明，不承诺所有属性自动热更新。

## 主角受击保护的唯一配置来源

`player/player_character.tscn` 的 Combatant 保存主角默认 `hit_protection_seconds = 0.5` 秒。它是可调整的场景默认值，不是 Player 启动时强制值；通用 Combatant 声明默认仍是 `0.0`。

Player 不重新赋值该属性。保存为零秒时连续有效命中不受计时限制；自定义合法时长控制实际命中窗口。重置清除剩余保护时间，保留配置时长。公共默认常量是默认值/设计出处，不能作为初始化时覆盖实例的依据；调整角色默认值同时更新场景、模块说明和对应验收。

## 当前程序管理的属性

| 属性 | 归属、覆盖时机与真正入口 |
| --- | --- |
| `MapExit.enabled` 与可见性 | MapWorld 挂载房间时按 `MapRegistry.connections` 的有向连接重新设置。模板中保存的 enabled 不是世界实例的路由开关；增删连接编辑世界注册资源。 |
| `MapExit` 碰撞层与掩码 | `_enter_tree()` 按专用角色检测契约设置；自定义检测规则应修改所属节点契约与回归。 |
| 训练场角色初始 `position` | TrainingArena 启动用 `PLAYER_SPAWN`、`DUMMY_SPAWN`、`ENEMY_SPAWN`，主角与敌人重置也使用相应常量。训练布局调整修改这些入口及设计基线；仅改场景 position 会在启动时被覆盖。 |

这些是已有程序管理契约，不是任意覆盖 Inspector 的许可，也不是本次新增玩法。房间入口的位置与朝向仍读取房间场景保存值。新增或修改程序管理属性时，同次提交在模块 README 标明真正入口、覆盖时机及原因。

## 每次变更的验证与交接

修改可配置属性的默认值、初始化、派生计算、重置或加载链时：

1. 使用正式场景/资源保存合法非默认值；允许时另测 `0` / `false`。从真实文件重载，避免仅验证内存对象或资源缓存。
2. 检查加入场景树后的最终配置，并验证实际行为，例如命中许可与保护结束时间。
3. 调用实际重置入口，检查运行状态清除且配置保留；派生值符合模块契约。
4. 通过统一测试入口执行，核对 manifest、完整报告、JUnit 和原始日志。新测试生成或流程修改后立即执行。
5. 同次提交更新所属模块 Markdown 与本契约的例外表；发现回归先查 [错误索引](errors/README.md)，保留原失败、修复和复验证据。

主角已有独立保存的零秒/0.2 秒继承场景、入树前配置，以及 `PackedScene.pack → ResourceSaver.save → CACHE_MODE_IGNORE` 真实往返用例。它们检验实际受击行为；静态检索只能辅助发现覆盖赋值，不能代替这些运行回归。
