# 第一版验收契约

> 本文件记录该版本的历史需求和验收。2026-10-02 心容器版本覆盖旧生命数值、增减伤公式与血条表现，稻草人改为 10 心归零回满；当前规则见 [heart-health-v5.md](heart-health-v5.md)。

## 用户授权范围

可运行的主角、基础移动与跳跃、普通攻击、火球术、gray box 地图、可被攻击的训练稻草人。先生成一版可替换角色占位图，具体手感与修改由用户试玩反馈。

## 可观察的验收条件

1. 使用项目固定的 Godot 稳定版可导入并启动主场景；真实游戏代码无解析或运行错误。
2. 主角可以左右移动、跳跃与落地，受平台、地板与墙体碰撞限制；空中不能无限连续跳跃。
3. 普攻具有近距离范围，面向目标且在范围内可命中；同次攻击不会每帧重复计算伤害，范围外不会命中。
4. 火球在前摇结束后向面朝方向发射，对目标造成一次伤害，遇墙、超出距离或寿命结束后清理。
5. 稻草人无限生命，显示受击反馈、命中次数与累计伤害；R 可重置角色、动作冷却、场上效果与统计。
6. 技能分阶段控制移动与取消规则，主动取消与受击中断分开（首版验证控制器 API，不包含取消按键/真实受伤链路）；火球 Lv.2 可降低前摇而不改基础伤害。基础定义不被等级解析污染。
7. 主角视觉与碰撞/伤害分开，替换素材不要求修改公共战斗逻辑。
8. 统一测试入口保留预期检查集合、原始日志、JUnit 结果、代码哈希和报告；空用例、跳过、超时、缺依赖不能视为通过。

## 首版实施假设

使用 GDScript，桌面键盘输入，单房间；所有移动与技能数值是调试初值。F2 是等级调试入口，不代表已实现技能树。没有正式动画，只有静态占位图与程序状态反馈。暂不包含互动道具、敌人 AI、完整技能树、存档、音乐、正式背景或发行包。

自动测试验证行为与工程运行；实际视觉查看验证当前画面。用户负责手感、可玩性及正式美术反馈，未收到反馈前不宣称用户验收通过。
